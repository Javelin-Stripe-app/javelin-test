# Improved Prompt

## Bug: Stripe App not retrieving data from user's Stripe account

### Environment
- Stripe App installed in my Stripe Dashboard (sandbox/test mode)
- Seed data is working — customers, and other objects exist in the account

### Problem
The app's AI chat interface cannot retrieve any data from my Stripe account.
When I ask "list my customers" (and customers exist in the account), it returns
no results. This appears to affect all Stripe data queries, not just customers.

### Expected Behavior
The AI assistant should query my Stripe account data via the backend
(Supabase Edge Functions → Stripe API) and return matching results.

### Actual Behavior
Every query returns empty/no results, as if the app has no access to my
Stripe account data.

### Debugging Needed
1. Verify the Stripe API key/OAuth token being used by Edge Functions
   — is it the correct sandbox account token?
2. Check if the `ExtensionContextValue` (user context, account ID) is being
   passed from the UI extension to the Edge Function
3. Inspect Edge Function logs for API call responses from Stripe
4. Confirm the app's `stripe-app.json` has the required permissions
   for reading customers and other objects
5. Check if the AI/LLM tool-calling layer is correctly invoking the
   Stripe data retrieval functions

### Key Files to Investigate
- stripe-app.json (permissions)
- Edge Functions that handle Stripe API calls
- The chat/AI interface component that sends queries
- Any auth/token middleware between UI and Edge Functions
