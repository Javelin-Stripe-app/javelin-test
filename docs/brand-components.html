Platform Constraints

All components operate within the Stripe Apps serialization model. These are non-negotiable platform limits that determine what is and isn't possible.

Non-negotiable Stripe Apps limits
  • Only Stripe UI Toolkit components — no raw HTML elements (<div>, <span>, etc.)
  • Only Box and Inline accept the css prop — all other components have preset styles
  • The css prop accepts design tokens only — no hex colors, RGB values, or arbitrary CSS strings
  • No custom fonts, no font-family overrides — Stripe controls all typography rendering
  • No localStorage, indexedDB, DOM manipulation, or ref props — sandboxed iframe with null origin
  • React 17 only — no React 18/19 hooks (useTransition, useDeferredValue, use())

Usage

  title="Update 23 subscriptions
    to the Pro plan"
  description="This will change the plan
    for 23 active subscriptions.
    2 with pending invoices will
    be skipped. Reversible."
  affectedItems={[
    { label: 'cus_001',
      detail: 'Pro → Enterprise' },

  confirmLabel="Update 23 subscriptions"
  onConfirm={handleConfirm}
  onCancel={handleCancel}
  destructive

JvLoadingState

Brand-consistent loading indicator with progressive status messaging. After 5 seconds (when startedAt is provided), the message updates and an extended-wait banner appears. Formalizes the ThinkingIndicator pattern.

Usage

  message="Fetching your top customers..."

// Progressive (auto-updates after 5s)

Brand Token Map

How Javelin's brand palette maps to Stripe's design tokens. Brand hex colors are reserved for the app icon, marketplace images, and external touchpoints only — never used inside the extension.

Color tokens
Stripe token Brand intent Javelin brand hex Fidelity
primary Accent / links / active states #4F46E5 (Indigo) Low — Stripe renders its own blue
success / Badge positive Success / positive metrics / live data #10B981 (Signal Green) Medium — both are green, exact shade differs
warning / Badge warning Warnings / attention / stale data #F59E0B (Alert Amber) Medium — both amber/yellow family
critical / Badge negative Errors / destructive actions — (not in brand palette) N/A — Stripe's native critical
container Card backgrounds / grouped content #F3F4F6 (Neutral 100) Medium — both are light gray
secondary Secondary text / labels / metadata Implicit secondary High — standard secondary treatment
Spacing vocabulary
Stripe token Pixel value Usage in Jv* components
xxsmall2pxBetween tightly coupled elements (metric label/value)
xsmall4pxBetween label and value, between icon and text
small8pxBetween items in a list, between buttons, between badges
medium16pxBetween content sections, container padding, page margin
large24pxEmpty state padding, between major page regions
